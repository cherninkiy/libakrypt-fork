# libakrypt-fork

`libakrypt-fork` — форк проекта `libakrypt`, криптографической библиотеки на языке C,
реализующей механизмы генерации,
хранения, экспорта и импорта ключевой информации, а также набор отечественных
криптографических преобразований, регламентированных национальными стандартами и
рекомендациями по стандартизации.

Этот репозиторий сохраняет исходную кодовую базу библиотеки и дополняет её текущей
структурой проекта, консольной утилитой `aktool`, тестами, примерами, документацией
и CMake-конфигурацией для сборки на Linux и других поддерживаемых
платформах.

## Возможности

- библиотека `libakrypt` с реализацией криптографических примитивов и служебной инфраструктуры;
- консольная утилита `aktool` для работы с ключами, ASN.1, конфигурацией и тестами;
- встроенные тестовые цели и набор примеров использования;
- документация и вспомогательные файлы для установки и сопровождения.

## Поддерживаемые платформы

Библиотека ориентирована на использование в `Linux`, `Windows` и `FreeBSD`.
В оригинальном описании проекта также упоминаются успешные тестовые запуски под
`ReactOS`, `Sailfish OS` и `PetaLinux`.

## Сборка

В репозитории уже настроены `CMakePresets`, поэтому базовый сценарий сборки выглядит так:

```bash
cmake --preset default
cmake --build --preset default
```

По умолчанию сборка выполняется в каталог `build/`, тип сборки — `Release`, а опция
`AK_TESTS` включена.

Альтернативный классический сценарий:

```bash
mkdir -p build
cd build
cmake ..
cmake --build .
```

После сборки в каталоге `build/` появляются библиотека `libakrypt` и исполняемый файл
`aktool`, а при включенных тестах — набор тестовых бинарников.

## Установка

Для установки собранных библиотек, заголовочных файлов, конфигурации и документации
используется стандартная команда CMake:

```bash
sudo cmake --install build
```

Если нужен нестандартный префикс установки, его можно задать на этапе конфигурации:

```bash
cmake --preset default -DCMAKE_INSTALL_PREFIX=/usr/local
cmake --build --preset default
sudo cmake --install build
```

В Unix-среде проект устанавливает:

- библиотеки в `lib`;
- заголовочные файлы в `include`;
- `libakrypt.conf` в системный каталог конфигурации;
- документацию и корневой сертификат библиотеки.

Для удаления установленного содержимого можно использовать файл `install_manifest.txt`,
который создаётся CMake во время установки.

## Запуск тестов

В preset `default` опция `AK_TESTS` уже включена, поэтому после сборки тесты можно
запустить так:

```bash
ctest --preset default
```

Альтернативно из каталога сборки:

```bash
cd build
ctest --output-on-failure
```

Для дополнительной проверки криптографических сценариев можно использовать `aktool`:

```bash
./build/aktool test --crypto --audit 2 --audit-file stderr
```

В репозитории также есть вспомогательный сценарий [libakrypt.test.sh](/home/dm/libakrypt-fork/libakrypt.test.sh),
который предназначен для расширенных прогонов на разных компиляторах.

## Структура проекта

```text
.
|-- aktool/                 исходники и ресурсы консольной утилиты aktool
|-- build/                  каталог локальной сборки и тестовых бинарников
|-- cert/                   сертификаты и связанные данные
|-- cmake/                  вспомогательные CMake-модули
|-- doc/                    документация проекта
|-- examples/               примеры и сценарии использования
|-- source/                 исходный код библиотеки и публичные заголовки
|-- CMakeLists.txt          корневой сценарий сборки
|-- CMakePresets.json       стандартные preset'ы конфигурации и сборки
|-- libakrypt.conf          файл конфигурации библиотеки
|-- libakrypt.test.sh       вспомогательный сценарий запуска тестов
|-- Changelog.md            журнал изменений
|-- LICENSE                 лицензия проекта
`-- Readme_libakrypt.md     исходное описание оригинального проекта
```

### Ключевые каталоги

- `source/` — реализация криптографических алгоритмов, ASN.1, работы с файлами,
  буферами, параметрами, случайными данными и служебной инфраструктурой библиотеки;
- `aktool/` — исходники CLI-утилиты, через которую можно запускать тесты,
  просматривать параметры, работать с ключевой информацией и ASN.1-структурами;
- `doc/` — исходники документации и конфигурация её генерации;
- `examples/` — демонстрационные примеры и дополнительные сценарии;
- `cmake/` — модули проверки флагов, заголовков, библиотек и настройки сборки.
