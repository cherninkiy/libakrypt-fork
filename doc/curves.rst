Математические свойства эллиптических кривых
=============================================
Определение эллиптической кривой над полем К в обобщенной форме Вейерштрасса базируется на уравнении 3-й степени

Используемые структуры и параметры
=============================================

Структуры:
---------------------------------------------

1. ak_wcurve

Описание

Структура, реализующая эллиптическую кривую, заданную в короткой форме Вейерштрасса.

y\ :sup:`2` + a\ :sub:`1`\xy + a\ :sub:`3`\y = x\ :sup:`3` + a\ :sub:`2`\x\ :sup:`2` + a\ :sub:`4`\x + a\ :sub:`6`\ , a\ :sub:`i`\  принадлежит К

Структура определяет эллиптическую кривую, заданную сравнением 



    y^2 \equiv x^3 + ax + b \pmod{p}

    а также образующую точку, \f$P=(x_P, y_P)\f$
    на этой кривой с заданным порядком \f$ q \f$.
    Порядок \f$ m \f$ всей группы точек эллиптической кривой может быть определен
    из равенства \f$ m = dq \f$, где величину \f$ d \f$ называют кофактором.

Поля структуры:

===============  ========== =====================
Поле             Тип        Описание
===============  ========== =====================

p                ak_uint64  Модуль p эллиптической кривой.
r2               ak_uint64  Величина r^2, взятая по модулю p и используемая в арифметике Монтгомери.
q                ak_uint64  Порядок q подгруппы, порождаемой образующей точкой P.
r2q              ak_uint64  Величина r^2, взятая по модулю q и используемая в арифметике Монтгомери.

n                ak_uint64  Константа n, используемая в арифметике Монтгомери по модулю p.  
nq               ak_uint64  Константа n_q, используемая в арифметике Монтгомери по модулю q.
pchar            const char Строка, содержащая символьную запись модуля p (Используется для проверки корректного хранения параметров кривой в памяти).

.. c:function:: int ak_wpoint_set( ak_wpoint, ak_wcurve )

Функция инициализирует и присваивает контексту значение образующей точки эллиптической кривой

   :param wp: Точка P эллиптической кривой, которой присваивается значение, содержащееся в контексте эллиптической кривой.
   :param wc: Эллиптическая кривая, которой принадлежит точка.
   :return: Функция возвращает \ref ak_error_ok. В случае, когда один  из контекстов равен NULL, то возвращается \ref ak_error_null_pointer.

.. c:function:: int ak_wpoint_set_as_unit( ak_wpoint, ak_wcurve )

Функция инициализирует и присваивает контексту значение бесконечно удаленной точки эллиптической кривой

   :param wp: Точка P эллиптической кривой, которой присваивается значение бесконечно удаленной точки.
   :param wc: Эллиптическая кривая, которой принадлежит точка.
   :return: Функция возвращает ak_error_ok. В случае, когда один  из контекстов равен NULL, то возвращается ak_error_null_pointer.

.. c:function:: int ak_wpoint_set_wpoint( ak_wpoint , ak_wpoint , ak_wcurve )

Функция инициализирует и присваивает контексту значение заданной точки эллиптической кривой

   :param wp: Точка P эллиптической кривой, которой присваивается новое значение.
   :param wq: Точка Q эллиптической кривой, значение которой присваивается.
   :param curve: Эллиптическая кривая, которой принадлежат обе точки.
   :return:  Функция возвращает ak_error_ok. В случае, когда один  из контекстов равен NULL, то возвращается ak_error_null_pointer.

.. c:function:: bool_t ak_wpoint_is_ok( ak_wpoint, ak_wcurve )

Функция проверяет принадлежность точки заданной кривой.

   :param wp: Точка P эллиптической кривой
   :param ec: Эллиптическая кривая, на принадлежность которой проверяется точка P.
   :return: Функция возвращает ak_true если все проверки выполнены. В противном случае возвращается ak_false. 

.. c:function:: bool_t ak_wpoint_check_order( ak_wpoint, ak_wcurve )

Функция проверяет порядок заданной точки. То есть проверяется выполнимость равенства \f$ [q]P = \mathcal O\f$,
    где \f$ \mathcal O \f$ - бесконечно удаленная точка (ноль группы точек эллиптической кривой),
    а \f$ q \f$ порядок подгруппы, в которой реализуются вычисления.


   :param wp: Точка P эллиптической кривой
   :param ec: Эллиптическая кривая, на принадлежность которой проверяется точка P.
   :return: Функция возвращает ak_true если все проверки выполнены. В противном случае возвращается ak_false. 

.. c:function:: void ak_wpoint_double( ak_wpoint, ak_wcurve )

Функция удвоение точки эллиптической кривой, заданной в короткой форме Вейерштрасса


   :param wp: Точка P эллиптической кривой
   :param ec: Эллиптическая кривая, на принадлежность которой проверяется точка P.
   :return: Функция возвращает ak_true если все проверки выполнены. В противном случае возвращается ak_false.
