Математические свойства эллиптических кривых
=============================================
Определение эллиптической кривой над полем К в обобщенной форме Вейерштрасса базируется на уравнении 3-й степени

Используемые структуры и параметры
=============================================

Структуры:
-------

1. ak_wcurve

Описание

Структура, реализующая эллиптическую кривую, заданную в короткой форме Вейерштрасса.

y\ :sup:`2` + a\ :sub:`1`\xy + a\ :sub:`3`\y = x\ :sup:`3` + a\ :sub:`2`\x\ :sup:`2` + a\ :sub:`4`\x + a\ :sub:`6`\ , a\ :sub:`i`\  принадлежит К

Структура определяет эллиптическую кривую, заданную сравнением 



    y^2 \equiv x^3 + ax + b \pmod{p}

    а также образующую точку, \f$P=(x_P, y_P)\f$
    на этой кривой с заданным порядком \f$ q \f$.
    Порядок \f$ m \f$ всей группы точек эллиптической кривой может быть определен
    из равенства \f$ m = dq \f$, где величину \f$ d \f$ называют кофактором.

Поля структуры:

===============  ========== =====================
Поле             Тип        Описание
===============  ========== =====================
size             ak_uint32  Размер параметров эллиптической кривой, исчисляемый количеством 64-х битных блоков.       
cofactor         ak_uint32  Кофактор эллиптической кривой - делитель порядка группы точек.
a                ak_uint64  Коэффициент a эллиптической кривой (в представлении Монтгомери)
b                ak_uint64  Коэффициент b эллиптической кривой (в представлении Монтгомери).
p                ak_uint64  Модуль p эллиптической кривой.
r2               ak_uint64  Величина r^2, взятая по модулю p и используемая в арифметике Монтгомери.
q                ak_uint64  Порядок q подгруппы, порождаемой образующей точкой P.
r2q              ak_uint64  Величина r^2, взятая по модулю q и используемая в арифметике Монтгомери.
point            wpoint     Точка P эллиптической кривой, порождающая подгруппу порядка q.
n                ak_uint64  Константа n, используемая в арифметике Монтгомери по модулю p.  
nq               ak_uint64  Константа n_q, используемая в арифметике Монтгомери по модулю q.
pchar            const char Строка, содержащая символьную запись модуля p (Используется для проверки корректного хранения параметров кривой в памяти).
===============  ========== =====================

Код ошибки   Название                        Описание
============ =============================== ========
