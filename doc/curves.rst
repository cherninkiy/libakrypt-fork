Эллиптические кривые
=============================================

Что такое эллиптическая кривая?
------------------------------------

Эллиптической кривой E называют кривую, которая имеет форму y^2 = x^3 + Ax + B, где A,B константы. 
Это уравнение называется уравнением кривой в форме Вейерштрассе. Необходимо опредлеить к какому множеству принадлежать A,B,x.
Обычно за них принимают элементы поля, например, действительные числа R, комплексные числа C, раицональные числа Q, одно из конечных полей Fp(=Zp) 
для просто числа p или одно из конечных полей Fq, q=pk с k>=1. 

Используемые структуры
---------------------------------------

Структура wpoint, реализующая точку эллиптической кривой
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Структура предсталяет собой точку P эллиптической кривой, заданной в короткой форме Вейерштрасса,
в проективных координатах, т.е точка представляется в виде вектора :math:`P = (x:y:z)`,
удовлетворяющего сравнению :math:`y^{2}z \equiv x^3 + axz^2 + bz^3 \pmod{p}`.
В дальнейшем, при проведении вычислений, для координат точки используется
представление Монтгомери.

Структура wpoint определяется следующим образом

.. code-block:: c

 struct wpoint
 {
   ak_uint64 x[ak_mpzn512_size];
   ak_uint64 y[ak_mpzn512_size];
   ak_uint64 z[ak_mpzn512_size];
 };

Контекст точки эллиптической кривой в короткой форме Вейерштрасса обозначется как ak_wpoint
  
.. code-block:: c

 typedef struct wpoint *ak_wpoint

 
Поля структуры:

========= ========= =========
Поле      Тип       Описание
========= ========= =========
x         ak_uint64 x-координата точки эллиптической кривой
y         ak_uint64 y-координата точки эллиптической кривой
z         ak_uint64 z-координата точки эллиптической кривой
========= ========= =========

Структура wcurve, реализующая кривую, заданную в короткой форме Вейерштрасса
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
 
Структура определяет эллиптическую кривую (в короткой форме Вейерштрасса), заданную сравнением
:math:`y^2 \equiv x^3 + ax + b \pmod{p}`, а также образующую точку, :math:`P = (X, Y, Z)` на этой кривой 
с заданным порядком :math:`q`. Порядок :math:`m` всей группы точек эллиптической кривой может 
быть определен из равенства :math:`m = dq`, где величину :math:`d` называют кофактором.

Параметры :math:`n, n_q, r_2` вводятся для оптимизации вычислений. Определим :math:`r = 2^{256}`
или :math:`r = 2^{512}`, тогда :math:`n \equiv n_0 \pmod{2^{64}}`, 
где :math:`n_0 \equiv -p^{-1} \pmod{r}`.

Величина :math:`r_2` удовлетворяет сравнению :math:`r_2 \equiv r^2 \pmod{p}`. 

Структура wcurve определяется следующим образом

.. code-block:: c

 struct wcurve
 {
   ak_uint32 size;
   ak_uint32 cofactor;
   ak_uint64 a[ak_mpzn512_size];
   ak_uint64 b[ak_mpzn512_size];
   ak_uint64 p[ak_mpzn512_size];
   ak_uint64 r2[ak_mpzn512_size];
   ak_uint64 q[ak_mpzn512_size];
   ak_uint64 r2q[ak_mpzn512_size];
   struct wpoint point;
   ak_uint64 n;
   ak_uint64 nq;
   const char *pchar;
 };

Контекст эллиптической кривой, заданной в короткой форме Вейерштрасса, обознается как ak_wcurve

.. code-block:: c

 typedef struct wcurve *ak_wcurve

Поля структуры:

===============  ========== =====================
Поле             Тип        Описание
===============  ========== =====================
size             ak_uint32  Размер параметров эллиптической кривой, исчисляемый количеством 64-х битных блоков.       
cofactor         ak_uint32  Кофактор эллиптической кривой - делитель порядка группы точек.
a                ak_uint64  Коэффициент a эллиптической кривой (в представлении Монтгомери)
b                ak_uint64  Коэффициент b эллиптической кривой (в представлении Монтгомери).
p                ak_uint64  Модуль p эллиптической кривой.
r2               ak_uint64  Величина r^2, взятая по модулю p и используемая в арифметике Монтгомери.
q                ak_uint64  Порядок q подгруппы, порождаемой образующей точкой P.
r2q              ak_uint64  Величина r^2, взятая по модулю q и используемая в арифметике Монтгомери.
point            wpoint     Точка P эллиптической кривой, порождающая подгруппу порядка q.
n                ak_uint64  Константа n, используемая в арифметике Монтгомери по модулю p.  
nq               ak_uint64  Константа n_q, используемая в арифметике Монтгомери по модулю q.
pchar            const char Строка, содержащая символьную запись модуля p (Используется для проверки корректного хранения параметров кривой в памяти).
===============  ========== =====================


Есть ли какие-то встроенные эллиптические кривые в libakrypt?
--------------------------------------------------------------
Да, в ``libakrypt`` есть несколько уже заданных эллиптических кривых 256 и 512 бит.

Эллиптический кривые 256 бит                         
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- **id_tc26_gost_3410_2012_256_paramSetTest** - Параметры 256-ти битной эллиптической кривой из тестового примера ГОСТ Р 34.10-2012
- **id_tc26_gost_3410_2012_256_paramSetA** - Параметры 256-ти битной эллиптической кривой из рекомендаций Р 50.1.114-2016 (paramSetA).
- **id_rfc4357_gost_3410_2001_paramSetA** - Параметры 256-ти битной эллиптической кривой, определяемые RFC-4357, set A (вариант КриптоПро). 
- **id_rfc4357_gost_3410_2001_paramSetB** - Параметры 256-ти битной эллиптической кривой, определяемые RFC-4357, set B (вариант КриптоПро). 
- **id_rfc4357_gost_3410_2001_paramSetC** - Параметры 256-ти битной эллиптической кривой, определяемые RFC-4357, set C (вариант КриптоПро).
- **id_axel_gost_3410_2012_256_paramSet_N0** - Параметры 256-ти битной эллиптической кривой, построенные в диссертационной работе Нестеренко А.Ю.

Эллиптические кривые 512 бит                         
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

- **id_tc26_gost_3410_2012_512_paramSetTest** - Параметры 512-ти битной эллиптической кривой из тестового примера ГОСТ Р 34.10-2012  
- **id_tc26_gost_3410_2012_512_paramSetA** - Параметры 512-ти битной эллиптической кривой из рекомендаций Р 50.1.114-2016 (paramSetA).
- **id_tc26_gost_3410_2012_512_paramSetB** - Параметры 512-ти битной эллиптической кривой из рекомендаций Р 50.1.114-2016 (paramSetB).
- **id_tc26_gost_3410_2012_512_paramSetC** - Параметры 512-ти битной эллиптической кривой из рекомендаций Р 50.1.114-2016 (paramSetC).
