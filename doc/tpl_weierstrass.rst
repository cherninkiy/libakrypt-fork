Операция утроения точки в форме Вейерштрасса.
==============================================

Конечной целью реализации операции утроения точки в форме 
Вейерштрасса является улучшение и модификация функции вычисления кратной точки эллиптической кривой.
Смысл в том, что можно разложить скаляр k в операции вычисления кратной точки kP на простые множители и "выделить" степень тройки ``n`` .
Таким образом можно модифицировать функцию вычисления кратной точки ``ak_wpoint_pow``, добавив утроение точки, повторяющееcя n раз.

Первый этап: реализация операции утроения
-------------------------------------------------

``void ak_wpoint_triple( ak_wpoint wp,  ak_wcurve ec)``

Функция перезаписывает в переменную ``wp`` значение 3P = 3 * P, где P - точка, которую необходимо утроить.

   :ak_wpoint wp: Точка, которую необходимо утроить
   :ak_wcurve ec: Эллиптическая кривая, заданная в короткой форме Вейерштрасса
   :return:    Функция не возвращает ничего

Для реализации данной функции использовался алгоритм ``tpl-2007-bl``

.. math::
    XX = X12
    YY = Y12
    ZZ = Z12
    YYYY = YY2
    M = 3*XX+a*ZZ2
    MM = M2
    E = 6*((X1+YY)2-XX-YYYY)-MM
    EE = E2
    T = 16*YYYY
    U = (M+E)2-MM-EE-T
    X3 = 4*(X1*EE-4*YY*U)
    Y3 = 8*Y1*(U*(T-U)-E*EE)
    Z3 = (Z1+E)2-ZZ-EE

Ссылка на источник: ``https://hyperelliptic.org/EFD/g1p/auto-shortw-jacobian-0.html#tripling-tpl-2007-bl``

Второй этап: модификация функции вычисления кратной точки
-------------------------------------------------

``void ak_wpoint_pow_modified( ak_wpoint wq, ak_wpoint wp, ak_uint64 *k, size_t size, ak_wcurve ec)``

Функция перезаписывает в переменную ``wp`` значение 3P = 3 * P, где P - точка, которую необходимо утроить.

   :ak_wpoint wq: Точка Q, в которую помещается результат
   :ak_wpoint wp: Точка P, которая возводится в степень.
   :ak_uint64* k: Степень кратности
   :size_t size: Размер степени k в машинных словах - значение, как правило,
    задаваемое константой ``ak_mpzn256_size`` или ``ak_mpzn512_size``. В общем случае
    может приниимать любое неотрицательное значение
   :ak_wcurve ec: Эллиптическая кривая, на которой происходят вычисления


Для заданной точки P = (x:y:z) и заданного целого числа k функция вычисляет кратную точку ``Q``, удовлетворяющую равенству ``Q = [k]P``

Для начала определяется сколько степеней числа 3 содержит k.
Это проверяется с помощью функции ``ak_mpzn_rem_uint32``, которая возвращает остаток от деления на число k. 
Пока остаток не будет равен числу больше нуля, продолжаем делить и увеличивать степень 3.
Получаем, ``сount`` степеней тройки у числа k. Затем применяется ``count`` раз операция утроения ``ak_wpoint_triple``, что должно ускорить функцию.
После оставшееся частное от деления на ``3^count`` подается агрументом в базовую функцию вычисления кратной точки.
